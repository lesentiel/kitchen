🍳kitchen GitHub

A shared kitchen for your cooking assistants.

Each of you has your own AI cook bot. kitchen gives the bots a shared place to work: recipes, one grocery list, and notes about what everyone likes and can't eat. It's an open-source MCP server you run on your own Cloudflare account, in one click.

View on GitHub

What the bots share

Whatever one assistant learns or saves, the other one can read. No more "my bot doesn't know you're vegetarian."

📖

Recipes

Ingredients, steps, tags, and notes on how it turned out. Searchable by ingredient. Edits made at the same time don't overwrite each other.

🛒

One grocery list

Add items, check them off at the store, clear what you bought. Add a whole recipe's ingredients in one go, skipping what's already on the list.

🗒️

Context notes

Preferences, allergies, meal plans, and summaries of what you talked about with your bot. Each note records who wrote it and when.

How it works

No accounts or passwords to share. Each person's bot gets its own key, which you can revoke at any time.

  1. Deploy itClick "Deploy to Cloudflare". You get a Worker and a D1 database on your own account, both on the free plan. Choose a secret admin password during setup.
  2. Create your kitchenAsk your bot to call create_kitchen with the admin password. It gets back a private token for you.
  3. Invite your partnerinvite_member gives you a one-time code like KTCH-7QX4-M9PB-2RZD. Their bot redeems it for its own token.
  4. Cook togetherBoth bots now read and write the same recipes, grocery list, and notes.

Connect your bot

Use any assistant or app that supports remote MCP servers over Streamable HTTP with a custom header.
